# Contributing

Thank you for your interest in SquashFS Delta Forensics Studio.

## Development Principles

- Preserve source-agnostic analysis
- Keep extraction and analysis layers separate
- Maintain compatibility with the canonical model contract
- Prefer reproducible and explainable analysis

## Pull Requests

Please:

- Open an issue before large design changes
- Include tests when possible
- Update documentation when introducing new features
- Maintain backward compatibility for report consumers

## Sample Data

Only synthetic datasets should be committed.

Do not contribute:

- Proprietary firmware images
- Internal datasets
- Customer data
- Confidential metadata
